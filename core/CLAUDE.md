# Khusus Claude Code

Ikuti seluruh protokol di AGENTS.md di atas. Ringkasnya:

1. Awal sesi: baca `.agent/HANDOFF.md`, `.agent/PLAN.md`,
   `.agent/DECISIONS.md`, `.agent/CONTEXT.md`, lalu cek `git status` / `git diff`.
2. Selama sesi: update `.agent/HANDOFF.md` setelah tiap langkah berarti.
3. Akhir sesi: lengkapi HANDOFF, tambah entri di `.agent/SESSION_LOG.md`,
   commit WIP dan push.
